# Museum Guide

A guide app for museums: audio tour, web guide, offline maps and media stations.

- Audio tour with stop-by-stop playback
- Web guide reachable by QR code at each stop
- Offline map tiles for buildings with weak signal
- Idle screen for media stations in the galleries

Pilot houses: Kunsthaus Ried, Technikmuseum Talfurt, Schlossmuseum Ebenried.
